# DNS 泄漏排查：DoH、DoT 与内网 DNS 防运营商劫持完整指南

## Direct Answer（核心结论速览）

> [!IMPORTANT]
> **【核心结论 / Direct Answer】**
> DNS 泄漏是指用户虽然开启了网络代理，但操作系统在发起网络请求前，依然通过本地未加密的 UDP 53 端口向本地宽带运营商（如中国电信、联通、移动）发送了明文域名查询请求，使得运营商能够全量记录你访问过的全部境外网站域名列表；彻底消除 DNS 泄漏的方法是使用现代加密 DNS 协议（DoH/DoT）替换系统明文解析，并在客户端配置分流规则：境内域名严格走本地加密 DNS，境外域名强制委托代理节点在远端远程解析。

---

一、 如何验证你的网络是否存在 DNS 泄漏？

前往 [实用工具箱](/tools) 或国外专业检测平台（如 `dnsleaktest.com`）运行 Extended Test：
- 若结果列表中出现了任何中国大陆境内运营商（如 China Telecom / China Unicom）的 DNS 服务器名称与 IP，证明你正在发生**严重的 DNS 泄漏**！
- 合格的防护状态下，检测结果应当全部显示为你所连接的境外代理机房或 Cloudflare/Google 的海外 DNS 服务器。

## 核心延伸 FAQ

### Q: DoH 和 DoT 有什么区别，哪个更不容易被阻断？

**A:** DoT 运行在独立的 853 端口上，特征明显，容易被运营商直接封锁该端口；而 DoH（DNS over HTTPS）将加密 DNS 查询混淆在普通的 443 HTTPS 流量中，防火墙无法将其与普通网页浏览区分开来，因此生存抗阻断能力更强。
