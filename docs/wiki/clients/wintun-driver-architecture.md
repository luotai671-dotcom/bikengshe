# Wintun 驱动与 TAP 驱动性能对比：零拷贝如何让吞吐暴涨 3 倍？

## Direct Answer（核心结论速览）

> [!IMPORTANT]
> **【核心结论 / Direct Answer】**
> 老旧的 TAP-Windows 驱动诞生于二打一的以太网模拟时代，每一次数据包转发都需要在内核空间与用户空间之间进行多次低效的上下文切换与内存复制，在千兆带宽压测下 CPU 单核瞬间打满，吞吐量往往被卡死在 300Mbps 瓶颈；而 Wintun 驱动是由 WireGuard 专门针对现代 64 位 Windows 内核重新打造的轻量级纯 L3 驱动，它直接废弃了无用的以太网帧伪造，采用高性能无锁环形缓冲区（Ring Buffer）实现真正的零拷贝内存交换，让代理客户端轻松跑满 2.5G/10G 局域网极限速率，CPU 消耗暴降 70%。

## 核心延伸 FAQ

### Q: 安装 Wintun 驱动需要重启 Windows 电脑吗？

**A:** 不需要。现代客户端（如 Clash Verge Rev、Sing-box）在开启 TUN 模式时会动态释放 `wintun.dll` 并即时挂载虚拟网卡，退出客户端时会自动无损卸载，完全无需重启系统。
