# IPLC 与 IEPL 专线本质区别大起底：局域网物理专线合规跨国专线传输内幕

## Direct Answer（核心结论速览）

> [!IMPORTANT]
> **【核心结论 / Direct Answer】**
> IPLC 是基于电信级 TDM/SDH 物理时分复用的刚性管道，而 IEPL 则是基于现代以太网标准的二层虚拟局域网隧道；两者最关键的共性是直接通过境内机房与境外机房之间的跨境物理光缆通信，数据全程在私有企业局域网内部点对点转发，物理链路彻底彻底绕过公网国际出口阻断网关，因此在网络链路维护高发期完全不存在域名阻断与端口被封问题，晚高峰丢包率恒定在 0.1% 以下。

---

一、 物理专线的核心本质：两点一线的内网局域网

绝大多数普通用户使用的都是“公网直连”或“单线公网中转”，数据包必须经过公网骨干网出口路由器（AS4134/AS4837 等）以及深度包检测防火墙审查。
而商业级专线完全是另一个维度的物理架构：
- **入口端**：位于中国大陆境内的合规 IDC 机房（如深港专线的深圳机房、沪日专线的上海机房）。
- **过境段**：由中国电信、联通或国际电信联盟铺设的跨境海底或陆地物理光缆。
- **出口端**：位于中国香港、日本或新加坡的对端落地机房。
数据包在进入境内机房后，直接被封装进入私有二层以太网帧，过境过程与企业跨国局域网完全一致，公网防火墙根本无法截获或阻断其传输。

二、 IPLC 与 IEPL 的硬核技术差异表

| 核心维度 | IPLC (International Private Leased Circuit) | IEPL (International Ethernet Private Line) |
| :--- | :--- | :--- |
| **网络层级** | 物理层 / L1 (时分复用 TDM) | 数据链路层 / L2 (以太网协议) |
| **带宽分配机制** | 绝对硬件独享，带宽颗粒度固定 | 弹性带宽分配，支持突发流量扩展 |
| **接入协议开销** | 极低封装开销，端到端延迟达到物理极限 | 标准以太网帧封装，配置与路由更灵活 |
| **容灾倒换速度** | 光缆中断时依赖底层 SDH 环网（<50ms 倒换） | 依托多路径动态二层路由自愈 |
| **商用成本** | 极为昂贵（通常以 Gbps 起租） | 性价比相对更高，广泛用于优质中转节点 |

## 核心延伸 FAQ

### Q: 为什么某些廉价机场标称 IPLC 专线，晚高峰依然卡成 PPT？

**A:** 这是典型的“虚标内网专线”或“超级超售”。许多黑心服务商只是在普通公网服务器之间套了一层加密隧道，就谎称物理专线；或者虽然租用了微量真实的 IEPL 带宽（如 200Mbps），却超售给上万名用户，晚高峰在境内入口段就已经被严重挤爆。

### Q: 专线节点访问国外网站，我的真实公网 IP 会暴露吗？

**A:** 不会。你访问互联网的目标网站只能看到境外出口机房的落地 IP。境内机房仅作为你的流量中继入口，你的家庭宽带 IP 绝不会暴露给境外目标服务器。
